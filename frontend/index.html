FRAUD INTELLIGENCE

Analyst-only fraud scoring

The available fraud dataset uses anonymized inputs (`V1`–`V28`), plus Time and Amount. Those values cannot be honestly collected through a normal customer form, so this dashboard does not pretend otherwise.

Use the documented `/api/v1/predictions/fraud` endpoint only with an authorized transaction system that supplies all 30 features. Scores create review alerts; they do not block transactions.
